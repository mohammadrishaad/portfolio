What this covers

This integration is for personal, non-commercial use. It connects my own Pinterest account to n8n workflows that I build and run myself, to automate tasks such as scheduling, organizing, or managing pins and boards on my own account.

Data collected

The integration only accesses data made available through the Pinterest API for the connected account, such as:

  • Basic account/profile information required for authentication

No data is collected from, or on behalf of, any third party or end user. No data from this integration is sold, shared, or used for advertising.

How data is used

Data retrieved via the Pinterest API is used solely within my own automation workflows (hosted in n8n) to manage my own Pinterest content. It is not stored beyond what is necessary for the workflow to run, and is not shared with any other service or party.

Data storage

Any temporary data used by the workflow stays within my personal n8n instance and is not transmitted to external services beyond Pinterest's own API.

Third-party sharing

I do not share, sell, or disclose any data obtained through this integration to third parties.
